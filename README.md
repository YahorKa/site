# Izo Studio — сайт изостудии (Жодино)

Новый сайт студии на Astro + Tailwind CSS. Старая версия (Rust/Yew) живёт в репозитории
`YahorKa/site` и остаётся как справочник по контенту.

## Запуск

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # сборка в dist/
npm run preview  # локальный просмотр сборки
```

## Где что лежит

- `src/data/site.ts` — весь контент: контакты, направления, услуги, преподаватель, галерея.
  Правьте здесь — страницы обновятся сами.
- `src/pages/` — страницы: главная, о студии, занятия, галерея, контакты, заявка, спасибо, 404.
- `src/components/` — шапка и подвал.
- `src/layouts/Base.astro` — `<head>`, метатеги, Open Graph, шрифты.
- `public/` — картинки, иконки, `robots.txt`, `sitemap.xml`.

## Форма записи

Форма на `/zayavka` размечена для **Netlify Forms** (`data-netlify`, скрытое поле `form-name`,
honeypot `bot-field`). При деплое на Netlify заявки появятся в разделе *Forms* панели сайта —
дополнительный сервис не нужен. Локально отправка не работает (нужен Netlify).

## Деплой

`netlify.toml` уже настроен: `npm run build` → `dist`. При подключении репозитория к Netlify
достаточно указать его как источник — остальное подхватится.
